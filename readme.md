# ChronoFusion AI – Smart Watch

Original smartwatch face for the Titan Watch Face Design Challenge 2026 (theme: **Design Time Your Way**, challenge option: Open Innovation).
One HTML file with CSS and JavaScript. No libraries, no network.

## No brand logo
The challenge forbids brand logos, so this design has none (no Titan logo). The shapes and icons are original.

## Features
- **Face:** large digital time, date and day, weather, Bluetooth, notifications, heart rate, steps, battery, seconds arc, 30° divisions
- **Analog style:** hour, minute and seconds hands, numerals, date window
- **Health page:** heart rate, SpO2, blood pressure, stress, sleep, temperature
- **Activity page:** three live rings for steps, calories and distance
- **Tools page:** stopwatch and 5-minute timer
- **Compass page:** live heading and a simulated hold-to-send SOS
- **Ambient (AOD):** black face with time, date and battery only
- **Palette:** obsidian black, brushed-metal bezel and face texture, titanium silver and gold
- **Signature element:** the Aurum Eclipse disc (darkens through the day) plus a glowing gold comet on the seconds arc
- **Typography:** tabular numerals, gold colon, tracked small-caps labels, hairline dividers
- **Weather page:** temperature, feels like, hourly outlook, high and low
- **Music page:** track controls, spinning disc, progress bar (simulated)
- **Breathe page:** guided inhale and exhale animation
- **AOD optimised:** outlined digits light fewer pixels, dimmed ticks, 30-second pixel shift against burn-in
- **Colourways:** gold, cyan, emerald, rose, titanium
- **Narrated tour:** START TOUR and STOP TOUR buttons walk through every feature with voice and captions
- Eight pages: swipe, use arrow keys, the dots or Prev/Next. Design size 466 x 466, text 21 px or larger, icons 25 px or larger.

Health, weather, music and compass data are simulated.

## Run
Open `index.html` in a browser. URL options: `?embed=1` hides controls, `?p=2` opens a page (0-7), `?a=1` analog, `?mode=amb` ambient, `?c=titanium` colourway, `?t=10:08` freezes the time, `?live=1` uses today’s date. By default the date shows 11/11/2026 (Wednesday).
