# Requirements – ChronoFusion AI Smart Watch

## Challenge rules
| Rule | Status |
|------|--------|
| Time display | 112 px bold digital time, plus analog style |
| Original work, no brand logos | Yes, none used |
| Text at least 21 px, icons at least 25 px | Yes (21 to 112 px text, 28 px icons) |
| 30° divisions, centred layout | 12 major ticks, centred components |
| Free fonts only | System fonts; use Inter or Rajdhani in Figma |
| Active and AOD previews | 1080 x 1080 PNGs |
| Figma editable link, named layers and frames | To do (tasks.md) |
| Concept: Figma track 2-3 sentences; form max 1024 chars | In readme.md |
| Window | 28/10/2026 to 06/12/2026 11:59 PM IST |

## Functional
- FR-1 Live clock, date shown as 11/11/2026 (DD/MM/YYYY, fixed for the preview), day, seconds arc; digital and analog styles
- FR-2 Complications: weather, Bluetooth, notifications, heart rate, steps, battery
- FR-3 Health page: heart rate, SpO2, BP, stress, sleep, temperature
- FR-4 Activity rings: steps, calories, distance
- FR-5 Stopwatch and timer
- FR-6 Compass and simulated SOS
- FR-7 Ambient mode (manual, auto after 30 s idle, tap to wake)
- FR-8 Five colourways (gold, cyan, emerald, rose, titanium), Workout simulation
- FR-11 Weather page, music page, guided breathing page
- FR-12 Signature Aurum Eclipse disc and seconds-arc comet
- FR-13 AOD optimisation: outlined digits, dimmed ticks, burn-in pixel shift
- FR-9 Swipe, keyboard, dots and buttons for navigation
- FR-10 Narrated tour (13 steps) with START and STOP buttons

## Non-functional
- One HTML file, offline, about 18 KB
- 466 x 466 base, scales to the screen
- High contrast, keyboard-focusable controls
